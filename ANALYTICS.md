# Chinese Character Stroke Order — Аналитика

## Продукт

Chrome-расширение + сайт [hsk-tutor.com](https://hsk-tutor.com) для изучения порядка черт китайских иероглифов. Пользователь устанавливает расширение, заходит на сайт (через клик по иконке или через контекстное меню на выделенном иероглифе), вводит иероглиф или рисует его от руки, смотрит анимацию черт и практикуется в написании.

Аналитика построена на **Amplitude** (события воронки, DAU, ошибки) и **GA4** (страницы сайта). Ключевая особенность — сквозная воронка: расширение и сайт работают в одном Amplitude-проекте, события связаны одним `device_id`, что позволяет видеть полный путь пользователя от установки до активного использования.

---

## Реализация

| Слой | Файл | Подключение |
|---|---|---|
| Расширение | `extension/lib/amplitude.js` | `importScripts` в background.js |
| Сайт | `frontend/js/amplitude.js` | `<script>` тег перед app.js |

**Сшивка воронки.** При переходе с расширения на сайт в URL добавляется параметр `?_amp=cso_xxx` (device_id расширения). Сайт считывает его, сохраняет в `localStorage` и использует как свой device_id — в Amplitude оба потока событий идут под одним устройством.

**device_id:** расширение генерирует `cso_xxx` и хранит в `chrome.storage.local`. Сайт генерирует `web_xxx` и хранит в `localStorage`, если не пришёл из расширения.

**API:** Amplitude HTTP API v2 (`POST api2.amplitude.com/2/httpapi`), публичный ключ `dd365ebb60dd430bea642a05b780de5b`. В каждом событии: `device_id`, `platform`, `app_version`, `language`, `time`.

## Воронка пользователя

```
[1] Расш_установлено
      └─ версия: "1.0"

[2] Расш_велком_страница_открыта
      └─ (сразу после установки, welcome page открывается автоматически)

[3] Расш_иконка_нажата
      └─ пользователь кликает по иконке → открывается сайт с ?_amp=device_id

[4] Сайт_открыт
      └─ из_расширения: true/false, сессия_номер, страница

[5] Сайт_иероглиф_загружен
      └─ иероглиф, черт (кол-во черт), письмо (упрощённое/традиционное)

[6] Сайт_практика_начата
      └─ иероглиф
```

На шаге [3] вместо иконки пользователь может использовать контекстное меню — тогда сайт открывается сразу на иероглифе, шаги [4]→[5] идут автоматически.

**Dropout-точки:**
- Между [2] и [3] — не заметил иконку / не закрепил расширение
- Между [4] и [5] — не нашёл нужный иероглиф (→ `Сайт_иероглиф_ошибка`)
- Между [5] и [6] — посмотрел анимацию, но не перешёл к практике

## Все события

### Расширение (`platform: Chrome Extension`)

| Событие | Свойства | Когда |
|---|---|---|
| `Расш_установлено` | `версия` | первая установка |
| `Расш_велком_страница_открыта` | — | первая установка |
| `Расш_обновлено` | `версия_новая`, `версия_предыдущая` | обновление |
| `Расш_иконка_нажата` | — | клик по иконке расширения |
| `Расш_контекстное_меню_нажато` | `символ_найден` (bool), `символ` | правая кнопка → Stroke Order |

### Сайт (`platform: Web`)

| Событие | Свойства | Когда |
|---|---|---|
| `Сайт_открыт` | `сессия_номер`, `из_расширения`, `страница` | загрузка страницы |
| `Сайт_иероглиф_загружен` | `иероглиф`, `черт`, `письмо` | успешная загрузка иероглифа |
| `Сайт_иероглиф_ошибка` | `запрос` | иероглиф не найден |
| `Сайт_повтор_анимации` | `иероглиф` | кнопка Replay |
| `Сайт_печать` | `иероглиф` | кнопка Print |
| `Сайт_практика_начата` | `иероглиф` | кнопка Practice |
| `Сайт_оценка_поставлена` | `оценка` (1–5) | клик по звёздочке |

В каждом событии сайта автоматически добавляются: `из_расширения` (bool) и `страница` (pathname).

## Воронка в Amplitude

Настроить через **Amplitude → Funnels → Create Funnel**:

```
Расш_установлено
→ Расш_иконка_нажата
→ Сайт_открыт         (фильтр: из_расширения = true)
→ Сайт_иероглиф_загружен
→ Сайт_практика_начата
```

Окно конверсии: 7 дней. Показывает процент пользователей, прошедших каждый шаг.
